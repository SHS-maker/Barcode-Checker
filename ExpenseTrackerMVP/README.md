# Expense Tracker MVP

This folder contains a ready-to-open SwiftUI starter app for a shared expense tracking app for two users.

It includes:
- dashboard with total spend and category breakdown
- transaction list
- budgets with progress bars
- bank connection placeholder screens for Sparkasse / Commerzbank
- mock data so the app is usable immediately

## What it is
This is a realistic MVP for a private household finance app, not a production bank integration. The project is designed as a starting point you can open in Xcode on a Mac and extend with Plaid, Tink, Salt Edge, or a direct bank API later.

## Open in Xcode
1. Copy this folder to your Mac.
2. Open the folder in Xcode as a SwiftUI app project.
3. Build and run on an iPhone simulator or a real device.

## Notes
- The app currently uses mock data.
- A production version should connect to a real Open Banking provider and store data securely.
- It is intentionally simple so a non-coder can understand the structure.
